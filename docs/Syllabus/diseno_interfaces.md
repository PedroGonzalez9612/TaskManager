## 2. Justificación

Este curso es importante en el programa porque apoya el diseño, implementación y evaluación de sistemas informáticos interactivos para ser utilizados por el ser humano, buscando optimizar el desempeño de sus actividades por medio del diseño de interfaces gráficas. Este curso le sirve al estudiante para seleccionar y aplicar formas, técnicas, mecanismos y estándares al momento de diseñar interfaces para la interacción entre el ser humano y la máquina consiguiendo que sean usables y accesibles.

## 3. Competencias previas

Identificar la metodología adecuada para el desarrollo de diferentes productos de software. Aplicar técnicas y procedimientos que permiten determinar los elementos necesarios de un proyecto de software y representar el dominio de la información. Desarrollar soluciones de software considerando los aspectos del modelo de negocios, mediante la aplicación de la metodología adecuada a la naturaleza del problema. Identificar las estructuras de un sistema gestor de base de datos. Clasificar los modelos de bases de datos orientados a objetos. Crear bases de datos.

## 4. Competencias

**Macrocompetencia:** Desarrollar sistemas informáticos aplicando el enfoque sistémico para proponer alternativas de solución a los problemas de las organizaciones.

**Unidad de competencia:** Diseñar sistemas informáticos para construir software de acuerdo a las necesidades del usuario utilizando metodologías de diseño vigentes.

**Elementos de competencia** (el original no detalla indicadores ni evidencias por elemento):
1. Establecer paradigmas de interacción humano-máquina y modelos cognitivos para interfaces gráficas de usuario.
2. Analizar metáforas para interfaces gráficas de usuario.
3. Diseñar interfaces para interacción humano-máquina.

**Problemas que resuelve:** desconocimiento de estándares universales en el diseño de interfaces gráficas de usuario; interfaces gráficas no accesibles por todo tipo de usuarios; interfaces gráficas no usables.

**Temas:**
- *Establecer paradigmas de interacción HM y modelos cognitivos para interfaces gráficas de usuario:* definición de interfaz; elementos de la interfaz; conceptos de UI/UX e interacción humano-computador (HCI); importancia del diseño de interfaces; ciclo de vida del diseño de interfaces; uso del mapa de empatía.
- *Elaborar metáforas para interfaces gráficas de usuario:* teoría del color; metáforas y su importancia en la interfaz HM; diseño de metáforas; tipos de usuarios en interacción HM; población especial; tipografía; iconos; consistencia visual.
- *Diseñar interfaces para sistemas informáticos:* normatividad vigente para interfaces (ley de accesibilidad); estándares para el diseño de interfaces; herramientas para evaluación de interfaces; wireframes; prototipos.

## 6. Evaluación

Para aprobar el curso se deben cumplir dos condiciones: la calificación mínima del curso debe ser 3, y cada una de las dimensiones (Saber, Ser, Hacer) debe tener una calificación mínima de 3.

**Cálculo de la nota:**
- Caso 1: si el estudiante aprueba todos los elementos de competencia, la nota final es el promedio de las notas obtenidas. Nivel: relacional o abstracto ampliado.
- Caso 2: si el estudiante reprueba todos los elementos de competencia, la nota final es el promedio de las notas obtenidas. Nivel: uniestructural o multiestructural.
- Caso 3: si el estudiante aprueba dos (2) de las tres dimensiones, la nota final es 2,7. Nivel: multiestructural.
- Caso 4: si el estudiante aprueba una (1) de las tres dimensiones, la nota final es 2,3. Nivel: multiestructural.
